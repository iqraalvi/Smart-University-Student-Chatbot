# 🎓 AI-Powered University Guideline Chatbot

An intelligent NLP-based chatbot system developed using Python and Sentence Transformers to assist students with university-related information such as attendance policies, GPA rules, room guidance, marking schemes, navigation, faculty offices, and more.

---

# 🚀 Features

* 📘 University guideline assistance
* 🏫 Room & lab navigation
* 📊 GPA and marking scheme guidance
* 🎓 Admission & scholarship information
* 🧠 Semantic NLP understanding
* 🔍 Handles different question tones
* ✨ Spelling mistake handling
* 🌐 Interactive Gradio chatbot interface

---

# 🛠️ Technologies Used

* Python
* Google Colab
* Pandas
* Sentence Transformers
* Scikit-learn
* Gradio
* NLP
* Cosine Similarity

---

# 🧠 AI Model Used

This project uses:

## Sentence Transformer Model

`all-MiniLM-L6-v2`

The model converts user questions into semantic embeddings and compares them with stored university questions using cosine similarity.

---

# 📂 Dataset

The dataset contains university-related question-answer pairs including:

* Attendance Policies
* Marking Schemes
* GPA Rules
* Faculty Offices
* Classroom Guidance
* Hostel Information
* Transport Information
* Navigation Assistance

---

# ⚙️ How It Works

1. User enters question
2. Question converted into embeddings
3. Similarity calculated
4. Best matching question identified
5. Corresponding answer returned
